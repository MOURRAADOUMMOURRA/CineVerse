# CineVerse

Application Android native développée en Java sous Android Studio.

## Fonctionnalités

* Recherche de films via l'API TMDB
* Affichage des détails des films
* Gestion d'une collection personnelle
* Sauvegarde locale avec SharedPreferences
* Interface moderne avec RecyclerView et CardView
* Chargement des affiches avec Glide

## Technologies utilisées

* Java
* Android SDK
* TMDB API
* Volley
* Glide
* RecyclerView
* SharedPreferences

## Auteur

Projet académique réalisé dans le cadre du cours de Développement d’Applications Mobiles à l’Université de Dschang.
